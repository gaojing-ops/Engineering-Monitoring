# 计算口径与核对示例

供 `SKILL.md` 第 3 节在执行监测计算时读取。以下公式与数据用于说明口径；项目批准的监测方案、仪器标定和基准定义决定实际使用方式。示例阈值不是工程默认值。

## 1. 规范化记录

建议每条观测保留这些字段；原始数据缺失时留空并标注原因：

| 字段 | 含义 |
|------|------|
| project_id / point_id / item | 项目、测点、监测项目 |
| observed_at / uploaded_at | 带时区的观测时间、上传时间 |
| source_type / source_ref | 自动化/人工/补录等来源，文件表格位置或记录 ID |
| raw_value / raw_unit | 未修改的原始值与单位 |
| value / unit / direction | 按已确认规则换算的值、单位和方向 |
| baseline_id / instrument_id | 基准版本、仪器标识 |
| quality_status / quality_reason | 有效、待复核、缺失、无效等状态及原因 |
| depth / axis | 测斜等项目的深度与轴向（适用时） |

按同测点、同指标、同轴向/深度和可比基准分组后按观测时间排序。观测值为 0 是合法数值，不能按空值删除。明确本期统计是“报告时点值”“当日最不利值”还是其他规则；不要静默选取最后上传的一条。

## 2. 变化量和变化速率

设统一单位与方向后的本次值为 x_t，上次可比有效观测为 x_p，初始值为 x_0：

```text
本期变化量 Δx = x_t - x_p
累计变化量 C = x_t - x_0
时间间隔 Δt_days = (t - t_p) 的实际经过秒数 / 86400
本期平均变化速率 v = Δx / Δt_days
```

变化量单位如 mm，速率单位如 mm/d。速率描述这段观测间隔的平均值，不能视为瞬时速率。若项目规定固定窗口或多次观测拟合速率，使用该规则并标明窗口和方法。

- 时间相同或逆序导致 Δt_days ≤ 0 时不计算速率，先处理重复、冲突或时间错误。
- 上次有效观测距离较远时保留实际间隔与缺测提示，不把跨日变化除以 1 天。是否允许跨缺测计算按项目配置，不能插补后冒充实测。
- 初始值、上次值、本次值的单位、基准和方向必须一致。初始值若由多次观测确定，记录其选取或平均依据。
- 阈值比较使用未做显示舍入的计算值；输出时按项目精度格式化，临界值可增加展示位数避免看似等于阈值而状态不同。
- 对十进制观测值的差分、换算和阈值边界，优先使用十进制定点或高精度十进制计算，避免二进制浮点误差改变等号判定。涉及三角函数时记录数值精度；不得临时增加容差来消除超限，比较精度策略须预先明确。

### 高程与沉降

原始高程为 m、输出为 mm 时先换算。若规定“高程降低为负”，累计变化为 `(H_t - H_0) × 1000`；若规定“沉降为正”，则为 `(H_0 - H_t) × 1000`。整份报告保持一致，并按同一方向转换阈值。

原始高差或未平差测量记录不能直接当作测点高程。需先按项目要求完成闭合差检查、平差及基准点稳定性复核；无法完成时输出待复核记录。

### 轴力、水位与裂缝

频率、电压、数字计数等原始量须使用对应传感器编号的标定公式和参数转换；不能猜测振弦频率平方系数、温度补偿或截面积。温度补偿仅按已确认公式执行。

轴力绝对值、轴力变化量、水位埋深、水位标高和裂缝宽度是不同指标。水位标高与埋深的转换需明确参考高程和向下为正等定义；阈值按指标逐项匹配，不把所有量都当成累计位移或使用绝对值比较。

## 3. 测斜数据口径

先确认数据属于原始读数、角度、局部段水平投影、累计剖面，还是相对初始剖面的位移。记录仪器类型、A/B 轴方向、深度排序、段长、角度单位和固定端。

- A+/A− 正反向读数的半差只有在仪器手册定义和标定系数明确时才能换算；半差本身不一定是角度，也不一定是 mm。
- 对相对竖直方向的角度 θ、已知段长 L，局部水平投影可按 `d_i = L_i × sin(θ_i)` 计算，三角函数输入使用弧度，结果单位与 L 一致。若角度定义相对水平面或设备有专用解算模型，应使用对应公式。
- 同一段相对初始的投影变化是 `δd_i = L_i × [sin(θ_i,t) - sin(θ_i,0)]`（段长不变时）。角度差、局部段投影变化和整孔剖面位移不能互换。
- 从固定端按确认的深度顺序、轴向符号累加各段投影，得到相对该边界的剖面。固定端有已知平移时按方案加入；固定端未知或不稳定时必须说明结果仅为所假定边界下的相对位移。
- 当前与初始剖面相减前核对相同深度、段长、安装方向和基准。输入若已是解算后的剖面或位移，不再乘段长或重复累加。
- 柔性阵列可能需要厂家提供的三维重建、扭转与温度修正模型。不能把单段公式当作所有型号的完整解算算法。

报告分别标注“段变化”和“相对初始剖面的位移”，极值注明深度与轴向。仅靠某一深度的跳变无法判断整孔侧移，需核对上下段、基准端和重复观测。

## 4. 阈值与极值

每条阈值配置明确：适用测点/项目、指标、单位、比较方向、等级、数值、有效期和依据。下列比较方式只是配置约定：

| 方式 | 达到阈值的判据 | 例子 |
|------|----------------|------|
| upper | x ≥ T | 裂缝宽度、轴力上限 |
| lower | x ≤ T | 水位标高下限、负向位移界限 |
| absolute | abs(x) ≥ T，T ≥ 0 | 项目明确按绝对值控制的位移或速率 |

示例采用等号触发；若项目批准规则不同，记录实际比较符号。上下限可同时存在。只配置控制值时只判断该值，不能自动补出预警值和报警值。不同指标分别判断，再按项目等级规则汇总。

同一指标的多级阈值必须按对应方向验证严格程度：upper/absolute 越大通常越严格，lower 越小通常越严格。等级顺序、单位或有效期冲突时先报告配置问题，不输出“正常”。

极值按项目要求同时报告代数最大、代数最小和最大绝对值（保留原符号）；风险汇总按实际触发方向选取最不利值。不要因负位移“数值小”而漏掉其绝对值超限。不同量纲的值不能放在同一排序中比较。

## 5. 基准变更

同一测点更换仪器或重埋后生成新基准版本。旧基准下的累计量与新基准下的累计量分开保留。只有联测确认的关系才可建立显示用转换：

```text
旧坐标系下的展示值 = 新坐标系观测值 + 经确认的偏移量
```

偏移量的符号、单位、来源记录和适用时间必须可核对。上述关系仅在两坐标系确实存在该平移关系时适用；不能默认拿“旧点最后值”与“新点第一个值”相减便是可靠拼接依据。跨版本变化与速率必须具有同样的可比依据，否则留空并标注基准变更。

## 6. 核对示例

以下均为合成示例，不对应真实项目。日期均为 2026 年，时区为 `+08:00`。

| 场景 | 输入与口径 | 应得到的结果 |
|------|------------|--------------|
| 非整日速率 | 初始 100.000 m，上次 99.998 m（11-08 08:00），本次 99.995 m（11-09 20:00），高程降低为负 | 本期 −3 mm；累计 −5 mm；间隔 1.5 d；平均速率 −2 mm/d |
| 阈值等号 | 上例按 absolute 方式，累计控制值 5 mm、速率控制值 2 mm/d | 两项均达到控制值，不能标正常 |
| 负向极值 | 同口径位移为 −12、+8、−3 mm | 代数最大 +8；代数最小 −12；最大绝对值对应原值 −12 mm |
| 疑似飞点 | 可换算的原值为 −25 mm，标记待复核，absolute 阈值为 20 mm | 保留 −25 mm 和超限提示，质量状态仍为待复核 |
| 时间冲突 | 同一测点同一时刻出现不同读数 | 标记冲突，不除以零，不擅自平均 |
| 缺少阈值 | 有有效观测但没有适用阈值 | 计算可用结果，阈值状态为未判定 |
| 重埋无联测 | 新点有初始值，但没有新旧基准关系 | 新旧曲线分段，不能计算跨版本变化或伪造连续累计量 |
| 测斜局部段 | L=1000 mm，相对竖直初始角 0°、当前角 1° | 该段投影变化约 17.4524 mm；整孔剖面仍须边界与其他段数据 |

应用这些示例核对计算口径后，仍需用实际文件验证来源映射、缺测覆盖、图表和报告的一致性；这些示例不构成任何工程或传感器型号的验收证明。
